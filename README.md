# مدار سوفت — أندرويد مستقل

تطبيق محاسبة عربي لأندرويد 8 أو أحدث، يعمل على الهاتف دون كمبيوتر أو خادم API أو SQL Server أو اتصال بالإنترنت. هذه نسخة تجريبية للتحقق؛ لا تستخدم بيانات متجر فعلية قبل تجربة الحفظ والاستعادة والطباعة على هاتفك.

تستخدم الواجهة شعار M المرفق مع ألوان الأزرق والسماوي، وفق آخر مرجع للمستخدم. شاشات الرئيسية والمخزون والفاتورة مخصصة للهاتف، والتنقل السفلي يدعم العربية من اليمين إلى اليسار. الأرقام في صور التحقق بيانات اختبار وليست بيانات متجر المستخدم.

## التشغيل

1. ثبّت APK الموقّع لمعمارية ARM64، ثم أنشئ حساب المدير واسم المتجر والعملة. لا توجد بيانات دخول افتراضية.
2. عرّف المنتجات ووحداتها وأسعارها، والعملاء والموردين.
3. افتح وردية الصندوق. سجّل التمويل، ثم الشراء لإدخال المخزون، ثم البيع.
4. من «المزيد» افتح التدريب لتجربة العمليات في قاعدة منفصلة.
5. من «النسخ والبيانات» شارك نسخة احتياطية خارج الهاتف.

## ما يعمل محلياً

- SQLite في مساحة التطبيق الخاصة؛ الحفظ المحاسبي والمخزون داخل معاملة واحدة، مع منع المخزون والنقد السالبين وتكرار طلب الترحيل.
- بيع وشراء نقدي وآجل وجزئي، مسودات، عملاء وموردون، تواريخ استحقاق وتحصيل وسداد موزع على أقدم الديون.
- وحدات متعددة بمعامل ثابت، باركود يدوي أو قارئ لوحة مفاتيح أو فك باركود من صورة كاميرا، أسعار مع تاريخ تغييرات.
- مستودعات ودفعات وصلاحية، منع بيع المنتهي، جرد وتسويات بسبب واعتماد المدير.
- فتح وإغلاق الصندوق وعد النقد ومراجعة الفروق، حسابات موظفين بثلاثة أدوار، وسجل توثيق.
- تقارير دخل ويومية وميزان مراجعة وربحية الأصناف ومقارنة الموردين والديون والمخزون والصلاحية؛ تصدير CSV وXLSX.
- مرفقات صور وPDF للفواتير، طباعة عبر خدمة أندرويد، واختيار 58/80 مم أو A4 في إعدادات الفاتورة.
- نسخة ZIP بقاعدة البيانات والمرفقات وملف تحقق SHA-256، استعادة مرحلية بعد فحص السلامة، ونسخة تلقائية محلية بعد العمليات المالية والمرفقات والاستيراد.
- استيراد تعريف المنتجات والأسعار من CSV وXLSX بعد المعاينة وفحص التكرار، وجولة تدريب تحفظ تقدم الموظف على قاعدة تدريب منفصلة.

الإصدار 2.2 يدمج نموذج Qwen3 0.6B محلياً بملف GGUF منفصل، مع وضع CPU خفيف يستهدف هاتف Galaxy A50 بذاكرة 4 غيغابايت. يُنزّل ملف النموذج مرة واحدة (نحو 484 ميغابايت) ويُستورد بعد التحقق من SHA-256، ثم تعمل الأسئلة العربية دون إنترنت. النموذج يقرأ ملخصاً محسوباً من البرنامج ولا يملك أدوات لترحيل الفواتير أو تعديل البيانات. يتضمن «التدريب العملي» ستة سيناريوهات متغيرة بأرقام افتراضية، وتصحيحاً موضوعياً وتلميحات ونتيجة وتقدماً محفوظاً لكل موظف. يستطيع المدرب المحلي شرح خطوة التدريب دون قراءة أرصدة المتجر؛ التمارين والتصحيح متاحان حتى قبل تنزيل النموذج. **استخراج بنود الفاتورة من الصور لم يُنفذ بعد**؛ الكاميرا تقرأ الباركود فقط. الرسوم المصغرة للمنتجات توضيحية حسب النوع، وليست صوراً يرفعها المستخدم.

## البيانات والترقية

النسخة المستقلة تنشئ قاعدة محلية جديدة. لا تنقل تلقائياً التاريخ المالي من SQL Server أو خادم النسخة السابقة. استيراد المنتجات لا يستورد الأرصدة أو الفواتير التاريخية. لا تُحذف قاعدة الخادم أو بيانات التطبيق القديمة بواسطة هذا التغيير.

معرف التطبيق باقٍ `com.supermarket.accounting`. تثبيت تحديث فوق النسخة القديمة يتطلب تطابق شهادة التوقيع؛ لا تحذف تطبيقاً يحتوي بيانات لتجاوز اختلاف التوقيع. احتفظ أولاً بنسخ البيانات من النسخة السابقة. APK التجريبي موقّع بمفتاح التطوير، وليس مفتاح إصدار دائم للنشر.

النسخة الاحتياطية غير مشفرة؛ احفظها في مكان خاص. رمز الدخول يحمي الواجهة وتخزن بصمته PBKDF2-SHA256، وقاعدة البيانات في مساحة التطبيق الخاصة وليست قاعدة مشفرة. لا توجد مزامنة أجهزة أو فوترة ضريبية أو مرتجعات حالياً.
